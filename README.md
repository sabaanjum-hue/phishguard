# PhishGuard

PhishGuard is a machine-learning project for detecting potentially phishing URLs using explainable URL-based features.

## Goal

Given a URL, PhishGuard extracts characteristics such as URL length, subdomain count, special characters, HTTPS usage, IP-address usage, and suspicious keywords. These features will later be used by a supervised machine-learning model.
